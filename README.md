# Jogo-incremental
A ideia desse projeto sera desenvolver um jogo no estilo incremental, com o tema de ceminterio, o jogo sera baseado no estilo de cookie cliker.

## Baixar e jogar no Windows

[Baixar Necromante Inc. para Windows](https://github.com/MecTrap/Jogo-incremental/raw/refs/heads/main/downloads/NecromanteInc-Windows.zip)

Extraia o ZIP completo e abra **Windows/NecromanteInc.exe**. Mantenha o executável e os demais arquivos juntos na pasta extraída. O jogo funciona sem abrir a Unity.

## Versão Unity

A versão Unity de **Necromante Inc.** está na pasta [NecromanteIncUnity](NecromanteIncUnity).

Abra essa pasta pelo Unity Hub com a Unity **6000.6.8f1**, carregue a cena **Assets > Scenes > Necromante** e pressione **Play**.

Ela inclui produção de recursos, monstros, evolução, automação, missões, conquistas, salvamento local e produção offline. A interface tem botões com feedback visual, painel de detalhes retrátil, barras de rolagem temáticas, menu integrado à arte, saldos atualizados e barra de XP.

Veja as [instruções do projeto Unity](NecromanteIncUnity/README.md) para jogar, editar e gerar um executável.
