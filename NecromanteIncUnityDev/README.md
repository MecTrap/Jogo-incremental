# Necromante Inc. — DEV para apresentação

Esta é uma cópia independente do projeto normal. Abra esta pasta pelo Unity Hub com a Unity 6000.6.8f1, ou jogue pelo executável NecromanteInc-DEV.exe do pacote para Windows.

## Painel de apresentação

Clique em Jogar. O painel DEV fica acima do mapa e começa visível. Os botões adicionam ouro, ossos, essência, Almas Eternas e XP. Clique em Quantidade para alternar entre os lotes:

| Lote | Ouro / Ossos | Essência | Almas Eternas | XP |
|---|---:|---:|---:|---:|
| Pequeno | 10.000 | 100 | 1 | 100 |
| Médio | 1.000.000 | 10.000 | 5 | 1.000 |
| Grande | 100.000.000 | 1.000.000 | 25 | 10.000 |

Mostrar DEV / Ocultar DEV recolhe o painel para liberar espaço no mapa. As compras, evoluções, missões e conquistas funcionam normalmente com os recursos adicionados. Ouro adicionado pelo painel não conta como ouro produzido.

## Roteiro rápido para a sala

1. Use o lote Médio ou Grande para adicionar recursos e mostrar compras e evoluções.
2. Clique em Preparar prestígio para alcançar pelo menos o nível 10 e abrir a confirmação normal do renascimento.
3. Confirme o prestígio. Repita cinco vezes para mostrar a coleção das relíquias e o final.
4. Prévia dos quadrinhos abre a sequência sem precisar fazer os prestígios. A prévia, antes de reunir as cinco partes, não marca a história como concluída.
5. Reiniciar apresentação exige confirmação e recomeça somente esta versão DEV.

## Salvamento independente

O nome do aplicativo é NecromanteIncDEV e o projeto tem um identificador próprio. O progresso usa a chave necromante-inc.dev-presentation.v1 e o volume usa necromante-inc.dev-presentation.music-volume. A versão normal usa outro nome e outras chaves; esta cópia não lê nem altera seu progresso normal. A demo é salva automaticamente e as ações do painel salvam imediatamente.

O código e os controles DEV estão apenas nesta cópia. Assets, Packages e ProjectSettings foram copiados da versão normal com o final, 33 objetivos e 46 conquistas.
